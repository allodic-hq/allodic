# @allodic/server

The self-hostable [allodic](https://github.com/allodic-hq/allodic) registry:
storefront, Stripe checkout, signed capability listings, per-buyer
fingerprinted delivery, entitled updates, refund-driven revocation, and
leak tracing. Runs on a $5 VPS or a laptop.

```bash
npx @allodic/server        # or: allodic-server (after install)
```

Configuration (Stripe, SMTP, BASE_URL, scan engines) and deployment:
https://github.com/allodic-hq/allodic/blob/main/docs/DEPLOY.md
